# Contributing

Thanks for helping improve Pyutube.

## Before You Open a PR

- Keep changes small and focused.
- Prefer functions over extra classes.
- Make sure the change works on Linux, Windows, and macOS.
- Run the checks in [QUALITY.md](QUALITY.md).

## Good PRs

- Include a short summary.
- Explain user-facing impact when behavior changes.
- Link the related issue if there is one.

## Ideas for Contributions

- Bug fixes
- Documentation improvements
- Small feature enhancements
- Verification and bug triage

## Need a Starting Point?

Look at open issues, typo fixes, logging cleanup, or small code health improvements.
